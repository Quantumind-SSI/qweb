Frequently Asked Questions

Answers about VICTRON hardware, security, shipping, and software integration.

VICTRON Specs

What is VICTRON?
VICTRON is QuantumindSSI VICTRON Platform hardware for sovereign edge AI. It ranges from bare-board modules to all-in-one field appliances.
Which configurations are available?
Configurations include VICTRON-BB, 2G/32GB, 4G/64GB, 8G/128GB, 16G sovereign models, 32G flagship models, and VICTRON-AIO variants.
Can it run AI locally?
Yes. VICTRON is built for local inference with optimized models, NPU acceleration, and optional Hailo-class accelerators.

Security

Does QSSI use post-quantum security?
Yes. QSSI systems are designed around post-quantum primitives such as ML-KEM and Dilithium for sovereign deployments.
Can VICTRON run air-gapped?
Yes. VICTRON can operate fully offline with no cloud dependency, making it suitable for defence, healthcare, industrial, and sovereign environments.
Is user data sent to QuantumindSSI?
No by default. QSSI architecture prioritises local processing and data sovereignty.

Shipping

When do VICTRON units ship?
Standard boards ship first, followed by sovereign models and all-in-one systems. Lead times vary by configuration and volume.
Do you support international orders?
Yes, subject to export-control requirements for cryptographic and advanced AI hardware.
Are enterprise volumes available?
Yes. QuantumindSSI supports pilot orders, enterprise batches, and custom deployment programs.

Software

Can teams deploy custom models?
Yes. VICTRON supports custom AI workloads, model optimisation, and sovereign application stacks.
Is fleet management cloud-based?
Fleet management can be self-hosted and air-gap compatible for sensitive deployments.
Which languages are supported?
QSSI developer tooling supports Python, C++, and Rust workflows for AI, robotics, and embedded systems.
